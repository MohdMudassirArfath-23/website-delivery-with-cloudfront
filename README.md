🌐 Website Delivery with CloudFront

 Project Overview

This project demonstrates how to deploy a static website on AWS using Amazon S3 and Amazon CloudFront. The website is securely hosted on Amazon S3 and delivered globally through CloudFront for faster performance, low latency, and high availability.

 AWS Services Used

- Amazon S3
- Amazon CloudFront
- AWS IAM
- S3 Bucket Policy
